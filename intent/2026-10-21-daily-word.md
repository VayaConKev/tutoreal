# 오늘의 단어 (쉬어 가는 게임)

- 날짜: 2026-10-21 (만든 뒤에 정리한 첫 의도 문서)
- 상태: 미리 보기 중 (선생님·테스터만, 시트 settings `daily_word_published` = preview)
- 관련 단계: 67~76단계, 앱 v0.72~v0.81, 서버 v0.50~v0.54

## 한 줄 요약

공부만 이어지면 지치니까, 연극의 막간이나 앨범의 스킷처럼 짧게 끼워 넣는 영어 게임. Wordle처럼 하루 한 단어를 맞히며 영어 자체에 흥미를 붙인다.

## 왜 만드나

- 챕터(대화·문장 연습)가 쌓일수록 앱이 '교재'처럼만 느껴진다. 말하기가 아니어도 영어에 흥미를 붙일 거리가 필요했다.
- 하루 한 단어라 매일 앱을 여는 이유가 생기고, 모두 같은 단어라 동료끼리 "오늘 거 몇 번 만에 맞혔어?"가 이어진다.
- 수업 단어(knees, sting, polyp 등)를 게임에서 다시 만나 복습이 된다.

## 누가 쓰나

- 영어 과정 학생: 내시경실 간호사, 초급. 휴대폰으로 출퇴근길·쉬는 시간에.
- 선생님·테스터: 학생에게 열기 전에 미리 보기로 시험하고, 앱을 바꿀 때마다 '다시 하기'로 다시 해 본다.
- 중국어 과정 학습자에게는 아직 보이지 않는다.

## 범위

**만드는 것**
- 챕터 목록 맨 위 카드, 6×5 칸 게임 화면, 화면 키보드, 결과 공유(색만), 연속 기록
- 시트 `words` 탭에서 단어·뜻·영어 힌트·수업 문장 관리, `daily_word_start`로 #1 날짜
- 대화 돌아보기 4/4 뒤에 한 번 권하기

**이번에는 안 만드는 것**
- 선생님 화면의 게임 통계, 순위표 (기록은 휴대폰에만)
- 중국어 버전 (나중에 '성조 맞히기' 같은 다른 게임으로)
- 4·6글자 단어 (긴 핵심 단어는 나중의 '듣고 받아쓰기' 게임에서)

## 지켜야 할 조건

- AI를 쓰지 않는다 → 비용 없음, 오프라인에 가까운 동작
- 한 단계에 기능 하나, 단계마다 CHANGELOG. 서버를 바꾸면 Code.gs 붙여 넣기 → 새 버전 배포 → setup()
- 학생에게 열기 전에 선생님·테스터만 미리 보기
- 초급 학생이 지치지 않게, 그러면서도 꼼수로 풀리지 않게

## 결정

| 정한 것 | 이유 | 버리거나 미룬 다른 안 |
| --- | --- | --- |
| Wordle 방식 (타이핑) | 말하기가 아니어도 영어 흥미를 붙이는 게 목적. 하루 한 판이라 짧다 | 듣고 받아쓰기, AI 스피드 퀴즈, 문장 조각, 짝 맞추기 (나중 후보) |
| 카드는 챕터 목록 **맨 위** | 매일 하는 게임은 눈에 띄어야 한다. 학생마다 진도가 달라 중간에 두면 못 보거나 스크롤해야 한다. 공부 전 몸풀기·중간 휴식 모두 학생이 고른다 | 2장과 3장 사이 (interlude 느낌은 좋지만 덜 보임). 대신 다 풀면 한 줄로 줄고, 대화 뒤에 한 번 권한다 |
| **5글자 고정** | 매일 같은 판이라 요령이 생기고, 공유 결과끼리 비교가 된다. 5글자 수업 단어도 충분하다 | 4~6글자 (수업 단어는 더 쓸 수 있지만 판이 매일 바뀜) |
| **사전에 있는 단어만** 입력 | 'AEIOU'·'AAAAA' 같은 글자 탐색 꼼수로 풀면 단어를 떠올리는 연습이 안 된다 | 아무 글자 허용 (처음엔 초급 배려로 골랐다가 바꿈). 사전은 퍼블릭 도메인 ENABLE 목록의 5글자 |
| 힌트는 **쉬운 영어 설명**, **3번째 시도부터** | 한국어 뜻은 너무 쉬워 게임이 싱거워진다. 영어 설명을 알아듣는 것 자체가 3주 차 주제(쉬운 말로 설명하기) 연습 | 한국어 뜻 힌트, 처음부터 열린 힌트. 설명이 없는 단어는 글자 하나를 알려 준다 |
| 한국어 뜻은 다 푼 뒤에만 | 정답과 뜻을 함께 보며 마무리 | — |
| 수업 문장 여러 개 중 하나를 무작위 | 실제로 쓰는 문장이 여러 개인 단어가 있다 (mouth 등). 화면이 좁아 한 번에 하나 | 모두 보여 주기 |
| 공유는 색만 (🟩🟨⬜), 힌트를 쓰면 💡 | 아직 안 푼 동료에게 스포일러가 되지 않게 | 정답 글자 포함 |
| 기록은 휴대폰에만, 서버는 단어만 정함 | 간단하고 비용·개인정보 부담이 없다 | 서버에 기록 저장 |
| 처음엔 미리 보기 (preview) | 학생에게 열기 전에 선생님·테스터가 충분히 시험 | 바로 공개 |
| 시험용 '다시 하기' (선생님·테스터만, 기록에 안 셈) | 앱을 자주 바꾸는데 하루 한 판이라 시험할 수 없었다 | 개인 탭에서 열기, 날짜 당기기 (임시 방법) |
| 칸 뒤집기는 출발 안내판(split-flap) 모양 | 맞혔을 때의 재미. '동작 줄이기'를 켠 사람에게는 끈다 | Wordle식 단순 뒤집기 |
| 두 번 눌러 확대 끄기 (두 손가락 확대는 유지) | KNEES처럼 같은 글자를 연달아 누르면 화면이 커졌다. 글씨 확대가 필요한 사람은 남겨 둔다 | 화면 전체 확대 금지 |
