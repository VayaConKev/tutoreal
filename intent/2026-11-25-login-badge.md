# 로그인 화면을 출입증 체크인으로

- 날짜: 2026-11-25
- 상태: 만드는 중 (125단계 끝, 2026-11-25)
- 관련 단계: 122~128단계 (서버 v0.72). 12-03 학습 경로 공개와 121단계(머리줄 통일) 뒤에 시작

## 한 줄 요약

접속 코드를 넣는 카드를 병원 출입증처럼 바꿔서, 학생이 앱을 여는 일을 "오늘의 3분, 체크인"으로 느끼게 한다.

## 왜 만드나

- 지금 로그인 화면은 흰 카드 한 장이라 밋밋하다.
- 코드가 틀렸을 때와 서버가 느릴 때 같은 회색 글씨 한 줄로 보여서, 학생이 무엇을 해야 할지 모른다.
- 매일 짧게 들어오는 습관을 출석 도장처럼 눈으로 보여 주고 싶다.

## 누가 쓰나

- 영어·일본어 과정 학생
- 선생님·테스터: 만드는 동안 이 기기에서 선생님·테스터 코드로 들어온 적이 있으면 새 화면을 먼저 본다.

## 범위

**만드는 것**
- 출입증 화면: 목걸이 줄·클립, 위쪽 구멍, 색 띠(상태 문구·날짜), 사진 자리(내 캐릭터), 소속·이름·역할, 가운데 영역, 점선, 하단 로고, 발급 정보(SINCE · No.)
- 상태 5가지: 첫 방문, 다시 온 학생, 체크인 성공, 코드 오류, 서버 지연
- 성공 상태의 NEXT CLASS 카드(다음 챕터 제목, 날짜, D-day)와 THIS WEEK 출석 도장(월~일 7칸)
- 움직임: 성공하면 찍히는 효과, 코드 오류면 좌우로 흔들림
- 서버: login 응답에 출입증 정보와 다음 수업 정보를 더한다
- 시트: students 탭 `badge_dept`, `badge_role`, `badge_no`, settings 탭 `next_class_chapter`

**이번에는 안 만드는 것**
- 서버가 주는 표(접속 코드 대신 쓰는 열쇠)로 바꾸기 — 서버 요청 14곳을 고쳐야 해서 따로 한다
- 출석 기록을 서버나 시트에 남기기
- 앱 전체 주 버튼 색 바꾸기 (#15336E는 로그인 화면에만)

## 지켜야 할 조건

- 출입증 높이는 모든 상태에서 같다. 안내 문구 자리를 늘 비워 두고 내용만 바꾼다. 테두리 두께는 늘 2px, 색만 바꾼다.
- 성공 상태에서 체크박스는 지우지 않고 숨기기만 한다 (버튼 위치 유지).
- 출입증은 테마와 상관없이 늘 라이트 색. 다크 모드에서는 배경, 상단, 제목, 목걸이 줄, 버튼만 어둡게.
- 띠 문구는 영어: TUTOREAL PASS / CHECKED IN / CHECK-IN FAILED / PLEASE WAIT
- 움직임 줄이기 설정을 켠 기기에서는 두 효과를 끈다.
- 출석 도장은 학생 기기에만 저장하고 서버로 보내지 않는다. 빈칸은 연한 점선으로만, "기록이 끊겼어요" 같은 문구는 쓰지 않는다.
- 한 단계에 기능 하나. 서버를 바꾸면 Code.gs 붙여 넣기 → 저장 → 새 버전 배포 → `setup()`.
- 수업 내용은 시트에만. 공개 저장소에 이름·접속 코드·브랜드를 쓰지 않는다.

## 성공 기준

- [ ] 상태 5가지에서 출입증 높이가 같다 (가짜 응답으로 375·320 폭에서 잰 숫자)
- [ ] 라이트·다크, 아이폰 홈 화면 앱·Safari 탭, 320 폭에서 넘치거나 겹친 곳이 없다
- [ ] 자동 체크인을 끄고 체크인하면 기기에 접속 코드가 남지 않는다
- [ ] 학습 단계 미리 보기가 아닌 학생 기기에서는 128단계 전까지 예전 화면 그대로
- [ ] `node tests/run-all.js` 통과 (122단계 test122 포함)
- [ ] 수업에서 학생이 코드 오류와 서버 지연을 구분한다 (125단계에서 화면은 만듦)
