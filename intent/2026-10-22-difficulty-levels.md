# 난이도 탭 (Beginner · Intermediate · Advanced)

- 날짜: 2026-10-22 (화면만 먼저 만든 뒤, 다음 단계를 위해 정리)
- 상태: 생각 중 — 탭 화면만 있음 (38단계, v0.42). Intermediate·Advanced를 누르면 '아직 준비 중이에요. Stay tuned!'
- 관련 단계: 38단계 (v0.42). 39단계로 만들었던 챕터 줄 나누기는 배포 전에 취소함

## 한 줄 요약

같은 상황(같은 장)을 실력에 맞게 세 단계로 연습하게 한다. 초급은 조각 하나씩, 중급은 조각을 잇고 돌발 상황에 대응, 고급은 처음부터 끝까지 한 번에.

## 왜 만드나

- 지금 학생은 모두 초급이라 모든 챕터가 Beginner다. 실력이 오른 학생이나 이미 영어가 되는 동료에게는 같은 챕터가 쉽다.
- 실제 업무는 조각이 아니라 한 흐름이다 (예: 결과 설명은 부위 안내 → 소견 여러 개 → 생활 습관 → 마무리). 조각을 다 익힌 뒤 이어 붙이는 단계가 필요하다.
- 같은 장 안에서 난이도만 올리면, 새 상황을 배우지 않고도 익숙한 장면에서 한 단계 더 연습할 수 있다.

## 누가 쓰나

- 영어 과정 학생: 지금은 모두 Beginner. 실력이 오르면 스스로 탭을 바꿔 도전.
- 선생님: 수업에서 다룬 장의 Intermediate·Advanced를 과제로 줄 수 있다.
- 중국어 과정: 지금은 고려하지 않는다 (같은 구조를 나중에 쓸 수 있음).

## 범위

**만드는 것**
- 시트 chapters 탭에 `level` 칸 (beginner / intermediate / advanced, 비우면 beginner) → 서버가 앱에 보냄 → 앱은 이미 그 값으로 탭별로 나눠 보여 준다
- 같은 장의 난이도별 버전은 **챕터 줄을 따로** 둔다 (예: `ch01` / `ch01-i` / `ch01-a`). 버전마다 scene·체크리스트·시나리오·문장 연습이 따로
- 목록에는 '1장 · Intermediate'처럼 장 번호와 난이도를 함께

**이번에는 안 만드는 것**
- 학생마다 난이도를 정해 주거나 자동으로 올려 주는 기능
- AI 수검자 지시문(프롬프트)을 난이도마다 따로 두기 — 지시문은 같이 쓰고 난이도는 scene·twist로 표현

## 지켜야 할 조건

- 한 단계에 기능 하나. 서버 변경은 Code.gs 붙여 넣기 → 새 버전 배포 → setup()
- 내용은 시트에만. 난이도별 내용이 늘어도 코드는 그대로
- 초급 학생이 겁먹지 않게: 기본 탭은 늘 Beginner, 다른 탭은 스스로 고를 때만
- Beginner에는 지금처럼 한국어와 영어 모범 문장을 함께 보여 준다 (영어를 따로 저장해 둔 것도 난이도별로 숨기거나 보이려고)

| 39단계(줄 나누기)는 배포 전에 취소 | Intermediate를 채우기 전에 **Beginner 상황을 먼저 더 늘리고 싶다** (선생님 결정) | 그대로 배포 |
| 3장의 '실제 설명 전체를 한 번에'는 Advanced (`ch03-a`) | 초급에게는 너무 길다. Beginner Part 1~5에서 조각을 익힌 뒤 이어 붙인다 | Beginner에 넣기 |
| (제안) 단계별 기준 — 아래 표 | 장마다 일관된 기준이 있어야 내용을 만들기 쉽고 학생도 예상할 수 있다 | 장마다 따로 정하기 |

**(제안) 단계별 기준 — 아직 확정 전**

| | Beginner | Intermediate | Advanced |
| --- | --- | --- | --- |
| 핵심 | 조각 하나씩 | 조각 2~3개 잇기 + 돌발 상황 대응 | 처음부터 끝까지 한 번에 |
| AI 상대 | 짧게, 협조적으로 | 되묻기·질문·증상 호소 같은 변수 | 자연스러운 속도, 후속 질문 |
| 영어 모범 문장 | 항상 보임 | 눌러야 보임 | 숨김 |
| (선택) 체크리스트 항목 | 해도 되고 안 해도 됨 | 일부는 꼭 | 모두 꼭 |

**(제안) 장별 내용**

| 장 | Intermediate | Advanced |
| --- | --- | --- |
| 1장 호명·본인 확인 | 알레르기 질문 추가 (`ch01-i` 초안 있음) | 동의서 문진: 과거력, 복용약, 헬리코박터 검사·치료 경험 |
| 2장 검사실 안내 | 녹내장이 있다고 답함, 혈관통에 놀람, 눈을 감음 같은 상황을 시나리오로, 문장 단위로 | 비수면 검사 안내 전체 |
| 3장 결과 설명 | 부위 안내 + 소견 하나 + 안심·생활 습관, 수검자 질문("Is it serious?", "Do I need medicine?"), 두통·어지러움 호소 → 쉬도록 안내 | 실제 설명 전체 (소견 여러 개) |

## 성공 기준

- [ ] 시트 `level` 칸을 서버가 보내고, 탭마다 그 난이도 챕터만 보인다 (가짜 시트 시험)
- [ ] 첫 Intermediate 챕터(`ch01-i`)를 열었을 때 Beginner 목록·기록·선생님 요약이 꼬이지 않는다
- [ ] 영어 모범 문장 보이기가 단계별 기준대로 동작한다
- [ ] 학생이 스스로 Intermediate에 도전하고, 피드백이 단계에 맞게 나온다

## 열린 질문 · 다음에 할 것

- 위 단계별 기준과 장별 내용을 이대로 갈지 (선생님 확인)
- 언제 시작할지: Beginner 3장(Part 1~3)이 어느 정도 나온 뒤로 미뤄 둠
- Intermediate가 비어 있는데 Advanced(`ch03-a`)가 먼저 생겨도 괜찮은지 → `ch01-i`를 Intermediate 첫 챕터로 먼저 여는 안
- 피드백을 난이도별로 다르게 할지 (예: Advanced는 gentle이 아닌 보통 피드백)
- 기록·선생님 요약에서 같은 장의 난이도를 어떻게 보여 줄지 ('1장 · Intermediate')
