# 중국어 과정 없애기

- 날짜: 2026-11-06
- 상태: 만드는 중
- 관련 단계: 101단계 v1.06 (서버 v0.65)

## 한 줄 요약

이용이 적은 중국어 과정을 앱과 서버에서 없애고, 영어·일본어 과정만 유지한다.

## 왜 없애나

- 중국어 과정은 이용률이 너무 낮고, 학생도 1명뿐이다.
- 코드에 중국어 전용 기능이 많아서, 고칠 때마다 함께 확인하고 시험해야 한다.
- 선생님 챕터 목록이 길어지는 원인 중 하나다.

## 누가 영향을 받나

- 중국어 과정 학습자 1명: 로그인과 내 기록을 더 쓸 수 없다. 멈추기 전에 선생님이 먼저 알린다.
- 선생님: 챕터 목록과 요약에서 중국어 과정이 사라진다.
- 영어·일본어 학생과 테스터: 바뀌는 것이 없다.

## 범위

**하는 것**
- 앱: 병음 변환(js/vendor/pinyin-pro.js 포함)과 중국어 전용 분기 삭제
- 서버: 중국어 지시문 5개, 예시 챕터와 addChineseSample, 중국어 피드백 형식, 받아쓰기 언어 설정 삭제
- 시험: 중국어를 쓰는 시험 8개 수정 또는 삭제
- 문서: README, CLAUDE.md, docs/content-guide.md에서 중국어 설명 삭제
- 시트(선생님이 직접): 사본 백업 → 학생 paused·챕터 비공개 → 배포 뒤 중국어 줄 삭제

**이번에는 안 하는 것**
- pinyin, better_py, py 칸 이름 바꾸기 (일본어 로마자도 쓴다)
- sessions 등 기록 탭의 중국어 줄 삭제
- CHANGELOG, 옛 의도 문서, 저장소 밖 인쇄물 고치기
- 영어 챕터 번호 ch를 en으로 바꾸기

## 지켜야 할 조건

- 영어·일본어의 동작은 그대로다. 일본어가 같이 쓰는 자막 도우미, gloss_model, 읽기 칸은 건드리지 않는다.
- 시트를 먼저 비공개로 한 뒤 서버를 배포한다. 순서가 바뀌면 선생님 화면에 대화가 시작되지 않는 중국어 챕터가 남는다.
- 공개 저장소에는 학습자를 역할로만 적는다.

## 결정

| 정한 것 | 이유 | 버리거나 미룬 다른 안 |
| --- | --- | --- |
| 중국어 과정을 코드까지 삭제 | 숨기기만 하면 고칠 때마다 계속 함께 확인해야 한다 | 시트에서 비공개만 하기 |
| 학생 줄은 paused로 남긴다 | 이번 달 사용 금액 계산과 기록이 sessions 탭의 학생 번호를 쓴다 | 학생 줄 삭제 |
| 기록 탭의 중국어 줄은 남긴다 | 이번 달 사용 금액 계산에 쓰인다 | 함께 삭제 |
| 선생님 휴대폰의 옛 중국어 기록은 볼 수 있게 둔다 | 저장된 병음과 뜻은 그대로 보이고, 기록을 지우지 않아도 된다 | 옛 기록 숨기기 |
| 대화 시작 때 걸어오는 수검자 그림은 영어·일본어 모두 그대로 (2026-11-21) | 지금도 중국어가 아닌 과정에 다 보인다. 학생 화면이 바뀌지 않는다 | 영어만 |
| 영어 챕터 번호는 ch로 유지 | 과정은 course 칸(en)으로 나누고, 코드는 번호 앞부분을 보지 않는다. 바꾸면 학생 진행 표시가 초기화된다 | ch를 en으로 변경 |
