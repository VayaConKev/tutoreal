# 일본어 과정 (내시경실 일본어, 시험용)

- 날짜: 2026-11-02
- 상태: 만드는 중
- 관련 단계: 93단계 v0.98 (서버 v0.58) ~ 96단계 v1.01 (서버 v0.61) 예정

## 한 줄 요약

선생님이 직접 공부하려고, 영어 과정과 같은 내시경실 커리큘럼을 일본어로 연습하는 시험용 과정(`ja`)을 만든다.

## 왜 만드나

- 선생님 개인 공부용에 가깝다. 영어 과정의 장면(호명·본인 확인, 검사실 안내, 결과 설명)을 일본인 수검자에게도 쓸 수 있으면 좋겠다.
- 영어·중국어 말고 세 번째 과정을 붙여 보면, 과정을 더하는 일이 얼마나 쉬운지(어디가 영어·중국어에만 맞춰져 있는지)도 확인된다.

## 누가 쓰나

- 선생님 계정 하나 (role teacher, 모든 과정을 봄). 일본어는 완전 처음 — 가나도 아직 모른다.
- 챕터는 `published=preview`로 둔다. 학생에게는 보이지 않는다.

## 범위

**만드는 것**
- 과정 칸 `ja` (과정 이름 '일본어'). 받아쓰기·자막은 일본어(ja-JP) + 한국어, 소리 내어 읽기도 일본어.
- AI 상대: 한국 건강검진센터에 온 일본인 수검자 (영어 과정과 같은 구조, 지시문 `ja-partner-…`).
- 자막은 늘 보이고(`ai_captions=show`), 일본어 아래에 **로마자 읽기**와 '뜻 보기'(한국어). 한자의 로마자는 휴대폰에서 바로 만들 수 없어(사전이 수십 MB) 중국어 '뜻 보기'처럼 서버의 가벼운 AI가 만든다.
- 힌트·피드백의 일본어 문장에 로마자와 한국어를 함께.
- 문장 연습 + 발음 코칭: drills `pron` 칸 = 문장 전체 로마자, 일본어 발음 기준 코칭.
- 콘텐츠: ch01·ch02·ch03·ch03b와 같은 내용의 ja01~ja04. 시트 줄(TSV)은 저장소 밖 `~/Documents/tutoreal-print/japanese/`, 작성 규칙은 `docs/content-guide.md`에 더한다.

**이번에는 안 만드는 것**
- 오늘의 단어 일본어판
- 일본어 학생 계정 (필요하면 나중에 students 탭에 course=ja 줄)
- 가나 표기로 바꿔 보기, 레벨(Beginner/Intermediate/Advanced) 탭

## 지켜야 할 조건

- 영어·중국어 과정의 동작은 바꾸지 않는다.
- 한 단계에 기능 하나. 서버를 바꾸면 Code.gs 붙여 넣기 → 배포 → (지시문·설정이 생기면) `setup()`.
- 의학 내용은 영어 과정의 병원 규칙을 그대로 따른다. 일본어 문장은 짧은 です・ます체, 굳어진 안내 표현만 경어.
- 수업 내용(챕터·시나리오·문장)은 시트에만. 지시문 기본값은 다른 과정처럼 setup이 prompts 탭에 넣는다.
- 공개 저장소에 이름·접속 코드 금지.

## 결정

| 정한 것 | 이유 | 버리거나 미룬 다른 안 |
| --- | --- | --- |
| 과정 코드 `ja`, 챕터 번호 `ja01`~ | 언어 코드와 같게, zh와 같은 규칙 | `jp` |
| 읽기는 로마자 | 가나를 아직 몰라서 | 히라가나 읽기, 읽기 없음 |
| 로마자는 서버 AI(가벼운 모델)가 만든다 | 한자 읽기를 휴대폰에서 만들려면 큰 사전이 필요 | 휴대폰 안 변환기 (kuromoji 등) |
| 문장 연습·발음 코칭까지 첫 범위에 | 혼자 공부할 때 가장 많이 쓸 기능 | 대화 + 피드백만 먼저 |
| 선생님 계정 + preview | 새 계정이 필요 없고 학생에게 안 보임 | 일본어 학생 계정 따로 |
| 커리큘럼은 영어 ch01~ch03b를 그대로 옮김 | 같은 장면을 두 언어로 연습 | 일본어용 새 장면 |
