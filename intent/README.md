# intent (의도 문서)

새 기능이나 새 콘텐츠 묶음을 만들기 **전에**, 무엇을 왜 만드는지 한 장으로 적어 두는 곳이다.
CHANGELOG가 '무엇이 바뀌었나'를 적는다면, 여기는 '왜 이렇게 정했나'를 적는다.
선생님과 Claude가 같이 읽는 기획서이고, 새 대화를 시작한 Claude도 이 문서로 맥락을 잡는다.

## 언제 쓰나

- 쓴다: 새 기능 (예: 오늘의 단어), 새 챕터 묶음 (예: 3장 Part 2), 화면 흐름이 바뀌는 큰 변경
- 안 쓴다: 버그 고치기, 문구 다듬기, 버전만 올리는 작은 변경 → CHANGELOG에만 적는다

## 어떻게 쓰나

1. 선생님이 하려는 일을 한두 줄로 말한다.
2. Claude가 먼저 묻는다: 누가 쓰나, 어디까지 만드나(안 만드는 것 포함), 지켜야 할 조건, 무엇이 되면 성공인가.
3. 답이 모이면 `_template.md`를 복사해 채운다. 파일 이름은 `날짜-짧은이름.md` (예: `2026-10-21-daily-word.md`).
4. 만들면서 정한 것이 바뀌면 '결정' 표에 이유와 함께 더한다. 끝나면 상태를 '완료'로.
5. 성공 기준은 가능하면 가짜 시트 시험(`tests/`)이나 화면 확인 항목으로 옮긴다.

## 공개 저장소 규칙 (꼭 지킬 것)

이 저장소는 공개돼 있다. 아래는 이 폴더에 **쓰지 않는다**.

- 학생·동료·학습자의 이름, 접속 코드, 브랜드 이름, 연락처
- 시트 주소, API 키, 결제 계정 번호, 메일 주소 같은 계정 정보
- 실제 수검자 정보, 병원 내부 문서의 원문
- 개인적인 이야기나 수업 밖의 사적인 내용

필요하면 '학생', '동료 간호사', '중국어 과정 학습자'처럼 역할로만 적는다.
