# 학습 단계 유도: 쉬운 문장 연습부터 AI 대화까지

- 날짜: 2026-11-21
- 상태: 생각 중
- 관련 단계: 102~109단계 v1.07~ (잠정, 중국어 과정 삭제 101단계 v1.06 / 서버 v0.65 다음)

## 한 줄 요약

AI 대화를 부담스러워하는 학생이 듣고 따라 읽기부터 자유 대화까지 6단계를 차례로 올라가도록, 챕터 화면을 단계 목록과 '다음 단계' 버튼으로 바꾸고 대화에 대본·큐카드 모드를 더한다.

## 왜 만드나

- 학생들이 문장 연습보다 AI 대화를 더 부담스러워해서 대화 이용률이 떨어졌다.
- 지금 챕터 화면은 가장 어려운 '대화 시작'이 주 버튼이고, 문장 연습과 대화 사이에 중간 단계가 없다.
- 문장 연습은 문장마다 표시만 남아서, 짧게 연습한 날은 '내 기록'에 아무것도 보이지 않는다.

## 누가 쓰나

- 영어·일본어 과정 학생 (휴대폰, 수업 사이 혼자 연습). Beginner와 Intermediate(동의서 문진) 챕터 모두
- 선생님·테스터 (먼저 미리 보기로 써 본다)

## 범위

**만드는 것**
- 학습 단계 6개: 문장 연습 1 듣고 따라 읽기(새로) → 2 빈칸 채우기 → 3 통째로 말하기, AI 대화 4 대본 보며 → 5 큐카드 보며 → 6 자유
- 묶음: drills 탭 group 칸으로 챕터 문장을 묶음(예: 시작 / 과거력 / 알레르기)으로 나누고, 진행률을 묶음 단위로 보여 준다 (예: 과거력 3 / 7). 칸이 비면 '전체' 한 묶음
- 챕터 화면: 두 버튼 대신 6단계 목록(완료 체크, 진행 중 표시). 하단 주 버튼은 늘 '다음 단계: (단계 이름) · (묶음 이름)'. 어느 단계든 직접 들어갈 수 있다
- 빈칸 단계: 문장 틀은 보이고 [대괄호] 부분(힌트 단어)만 빈칸. 문장 전체가 [대괄호]인 단어 문항은 지금처럼 전체가 빈칸
- 묶음 완료 화면: "방금 연습한 문장으로 AI 수검자와 대화해 볼까요?"와 버튼 셋 ('대본 보며 대화하기' 주 버튼, '다음 묶음', '오늘은 여기까지')
- AI 대화 화면 위 '대본 / 큐카드 / 자유' 탭 (문장 연습 단계 탭과 같은 모양)
  - 대본: 하단 카드에 대본 전체(간호사 대사 + 수검자 기본 답), 다음 간호사 대사를 강조
  - 큐카드: 같은 자리에 한국어 큐만
  - 자유: 힌트 버튼만. 누르면 힌트 단어 하나
- 홈: 오늘의 단어 카드 위에 '이어서 하기' 카드 (마지막 챕터·단계·묶음과 진행률)
- 학습 기록: 단계·묶음 완료 개수, 짧은 문장 연습도 '내 기록'에 남는다
- 시트 칸 추가 (기존 칸 이름은 그대로, 맨 오른쪽에 setup이 더함)
  - drills: group (묶음 이름), kind (word / sentence, 비우면 자동), cue (한국어 큐, 비우면 situation)
  - scenarios: answers (AI 수검자 기본 답, 한 줄에 하나, `d04: No, I don't.`처럼 문장 번호를 앞에), variants (변형 목록, 한 줄에 하나)
  - sessions: mode (script / cue / free, 서버가 적는다)
- settings: learning_path_published (preview / TRUE / FALSE, 오늘의 단어와 같은 뜻)

**이번에는 안 만드는 것**
- 턴별 대사 추적 (대본 강조는 내가 말한 횟수로 대략 옮기고, 줄을 눌러 고친다)
- 선생님 대시보드 개편, 학습 기록의 서버 저장
- 일상 문장 틀 콘텐츠
- 듣고 따라 읽기의 AI 발음 코칭 (나중에 붙일 수 있게만 둔다)
- 대화 중 AI 답 방식 바꾸기 (탭은 화면 카드만 바꾼다)

## 지켜야 할 조건

- 한 단계에 기능 하나. 서버를 바꾸면 Code.gs 붙여 넣기·배포·setup
- 수업 내용(묶음, 큐, 기본 답, 변형)은 시트에만. 코드에 넣지 않는다
- 새 칸이 빈 챕터·시나리오는 지금과 똑같이 동작한다 (시험으로 확인)
- 기존 기록(tutoreal.history, tutoreal.drills)과 백업 파일 모양은 바꾸지 않는다. 새 기록은 tutoreal.practice에 따로
- 새 AI 호출을 만들지 않는다 (힌트 단어·따라 읽기는 비용 없음). 월 예산 $15, 하루 30분·연결 20번은 그대로
- 의학 내용이 들어가는 기본 답·변형은 병원 기준. 모르면 묻는다
- 공개 저장소: 이름·접속 코드·시트 주소를 쓰지 않는다
