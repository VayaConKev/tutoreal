# 오늘의 단어 한 마디로 설명하기

- 날짜: 2026-10-26
- 상태: 만드는 중
- 관련 단계: 87단계 v0.92 (서버 v0.55)

## 한 줄 요약

오늘의 단어 게임이 끝나면(맞혀도, 못 맞혀도) 그 단어를 **쉬운 영어 한 문장으로 설명**해 보고, AI가 뜻이 통하는지와 문법·다른 표현을 짧게 알려 준다.

## 왜 만드나

- 영어 과정의 핵심은 검사 결과를 영어로 설명하는 것이고, 그 기초 체력은 **어려운 단어를 쉬운 일상 말로 한 문장에 풀어 말하는 힘**이다 (3장의 ③ "It means …", 3주 차 워밍업 스피드 퀴즈).
- 지금 게임은 단어를 맞히고 예문을 보거나 듣는 데서 끝나서, **문장을 직접 만들어 보는 연습**이 없다.
- 하루 한 단어라 부담이 작고, 이미 매일 여는 화면에 붙이면 따로 시간을 내지 않아도 된다.

## 누가 쓰나

- 영어 과정 학생: 내시경실 간호사, 초급. 휴대폰으로 출퇴근길·쉬는 시간에 (소리 없이 타이핑).
- 선생님·테스터: 미리 보기로 시험하고, '다시 하기'로 처음부터 다시 해 본다.
- 중국어 과정에는 오늘의 단어가 없으므로 해당 없음.

## 범위

**만드는 것**
- 게임 끝 화면(정답·뜻이 보인 뒤)에 "그럼 오늘의 단어를 한 마디로 설명해 볼까요?" 칸: 문장 입력, 설명 틀 도움말, '피드백 받기', '건너뛰기'
- AI 피드백: 뜻이 통하는지(3단계), 문법을 고친 문장, 다른 쉬운 표현 1~2개 (🔈 듣기)
- 다시 써 보기 (하루 횟수 제한 안에서)
- 쓴 문장과 피드백을 휴대폰에 저장해, 같은 날 다시 열면 그대로 보이기

**이번에는 안 만드는 것**
- 말로 설명하기(🎤) — 받아쓰기 오류 없이 문법을 정확히 보려고 타이핑만
- 서버·선생님 화면에 학생 문장 저장 (서버에는 횟수와 비용만 남긴다)
- 게임 기록(연속 기록·맞힌 날)과 연결하기
- 중국어 버전

## 지켜야 할 조건

- 설명은 **선택**이다. 게임 결과와 연속 기록은 지금처럼 게임이 끝나는 순간 저장되고, 설명을 건너뛰거나 도중에 앱을 닫아도 사라지지 않는다.
- 학생이 쓴 문장과 피드백은 **그 휴대폰에만** 저장한다.
- AI 비용: 오늘의 단어는 원래 AI를 쓰지 않는 게임이었다. 이 단계만 짧은 글 피드백(빠른 모델, 가장 짧은 생각)을 쓰고, 하루 횟수 제한과 월 예산 안에서만 동작한다.
- 피드백은 너그럽게(gentle): 목표는 '뜻이 통했나'. 해요체.
- 한 단계에 기능 하나 + CHANGELOG. 서버를 바꾸면 Code.gs 붙여 넣기 → 새 버전 배포 → setup().

## 결정

| 정한 것 | 이유 | 버리거나 미룬 다른 안 |
| --- | --- | --- |
| 정답이 공개된 뒤(맞혀도, 못 맞혀도) 끝 화면에서 권하기 | 정답을 알아야 설명할 수 있다. 못 맞힌 날에도 연습은 할 수 있다 | 맞힌 날만 |
| **타이핑**으로 입력 | 게임이 타이핑이라 흐름이 자연스럽고, 받아쓰기 오류가 없어 문법 피드백이 정확하다. 소리 없이 할 수 있다 | 말하기(🎤), 둘 다 |
| **건너뛸 수 있음**, 게임 기록과 따로 | 바쁜 날 게임 자체를 미루지 않게. 설명을 마치면 카드에 ✍️ 표시 | 설명까지 해야 '완료'·연속 기록 |
| 문장과 피드백은 **휴대폰에만** | 학생이 부담 없이 쓰게. 만들 것이 적다 | 서버에 저장해 선생님이 보기 |
| **정답 단어를 쓰지 않기** | 3주 차 스피드 퀴즈와 같은 규칙. 단어를 쓰지 않고 풀어 말하는 게 결과 설명의 핵심 | 써도 됨. 정답 단어(복수형 등 포함)가 들어 있으면 AI에 보내기 전에 앱이 바로 알려 주고, 횟수도 줄지 않는다 |
| 힌트 문장을 그대로 써도 받아 준다 | 따라 쓰는 것도 의미가 있다. 다만 피드백이 "내 말로 바꿔 보면 …"을 하나 권한다 | 힌트 문장 거절 |
| 피드백 = 통함 판단(3단계) + 고친 문장 + 다른 표현 1~2개 | 대화 피드백(gentle)과 같은 틀이라 학생에게 익숙하다. 짧아야 끝까지 읽는다 | 긴 설명, 점수 |
| 설명 틀 도움말: It's in your ___. / You use it to ___. / It's like ___. | 스피드 퀴즈 때 칠판에 적은 틀. 막힌 초급 학생의 시작을 돕는다 | 도움말 없음 |
| 서버에는 횟수·비용만 기록 (문장은 보내지만 남기지 않음) | 하루 제한과 월 예산 계산에 필요하다 | 기록 없음 |
| 피드백은 학생 하루 3번 (settings `daily_explain_limit`), 선생님·테스터는 제한 없음 | 비용을 묶어 두면서 한 번은 고쳐 쓸 수 있게. 선생님은 '다시 하기'로 자주 시험한다 | 1번만, 제한 없음 |
| 설명을 마치거나 건너뛴 뒤에 수업 문장·기록·공유가 보인다 | 설명이 게임의 마지막 단계로 느껴지게. 수업 문장이 먼저 보이면 그대로 베끼기 쉽다 | 모두 한 화면에 |
| 설명을 마친 날은 카드와 공유 글에 ✍️ | 힌트의 💡처럼 한눈에 보이고, 동료끼리 자극이 된다 | 표시 없음 |

## 성공 기준

- [ ] 가짜 시트 시험: 피드백 요청이 하루 제한·월 예산을 지키고, 기록 탭에 문장이 남지 않는다
- [ ] 휴대폰 크기 화면: 끝 화면에서 설명 칸 → 피드백 → 다시 써 보기, 같은 날 다시 열면 그대로, 건너뛰어도 기록 그대로
- [ ] 정답 단어가 들어간 문장은 AI에 보내기 전에 걸러진다
- [ ] 수업: 학생들이 게임 뒤에 설명까지 해 보고, "쉬운 말로 한 문장" 연습이 결과 설명(③ It means …)에 이어진다
